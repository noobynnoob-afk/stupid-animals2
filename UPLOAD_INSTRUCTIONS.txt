STUPID ANIMALS - 휴대폰 GitHub 업로드

GitHub 저장소 최상위에 올릴 파일:
package.json
server.js
render.yaml
index.html
game.js
README.md

중요: public 폴더는 필요 없습니다.
이미 올린 4개 파일은 그대로 두고 index.html, game.js, server.js만 추가 또는 교체해도 됩니다.
GitHub에서 파일 이름이 같으면 기존 파일 수정이 필요할 수 있습니다.

Render:
New > Web Service > GitHub 저장소 선택
Build command: npm install
Start command: npm start
무료 플랜이 있다면 선택

주의: README.md와 UPLOAD_INSTRUCTIONS.txt는 실행에 필수는 아닙니다.
