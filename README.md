STUPID ANIMALS v0.6
수정 사항
- 모바일 조이스틱 Y방향 수학적 수정: 위쪽 터치 y<0 -> z<0(전진), 아래쪽 y>0 -> z>0(후진), 카메라 각도 0 기준.
- 모바일 잠금(시프트락 ON): 캐릭터가 카메라 방향을 바라보며, 오른쪽 화면 드래그로 자유롭게 시점 회전.
- 모바일 자유 시점: 버튼을 누르면 카메라가 캐릭터 앞으로 돌아가 얼굴이 보임. 이후 오른쪽 드래그로 360도 자유롭게 둘러볼 수 있고 가만히 있어도 카메라 조작 가능.
- PC P키: 브라우저 마우스 포인터 잠금/해제.
- 이전 v0.4 총격, 피격 점멸, 데미지 숫자, 채팅, 이모트 유지.
주의: 카메라 앞의 지형 충돌 방지 및 완전한 3인칭 자유 조준과 캐릭터 방향 분리 등은 추가 개선 여지 있음. 실제 모바일 테스트는 미수행.
