# STUPID ANIMALS — 공개 3D 멀티플레이 웹게임

닉네임 → 캐릭터 3종 → 총 6종 → 모든 접속자가 하나의 맵에서 플레이합니다. PC와 모바일 브라우저 지원. 테스트용 저폴리곤 모델이며 외부 3D 라이브러리(Three.js)를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 로컬 실행 (PC)
1. Node.js 20 이상 설치
2. 이 폴더에서 터미널 열기
3. `npm install`
4. `npm start`
5. `http://localhost:3000` 접속

## 공개 링크 만들기 (GitHub + Render)
1. GitHub에 새 **공개 또는 비공개** 저장소 생성.
2. 이 폴더의 파일 `server.js`, `package.json`, `render.yaml`, `public/index.html`, `public/game.js` 업로드. (폴더 구조 유지)
3. https://dashboard.render.com 에 가입하고 **New > Web Service** 선택.
4. GitHub 저장소 연결, 런타임 Node, Build Command `npm install`, Start Command `npm start`. 무료 플랜이 표시되면 선택 (플랜 제공 여부와 제한은 시점/계정에 따라 다를 수 있음).
5. 배포 완료 후 Render가 발급한 `https://...onrender.com` 주소를 친구에게 공유.
6. PC와 모바일에서 같은 링크로 들어와 각자 닉네임/캐릭터/총을 선택하면 함께 플레이 가능.

## 주의
- 하나의 Node 프로세스/인스턴스에서 모두 같은 공개 맵으로 연결됩니다. 서버가 재시작되면 접속이 끊기고 진행 상태는 저장되지 않습니다.
- 무료 서버는 유휴 상태에서 잠들 수 있어 첫 접속이 느릴 수 있습니다.
- 15명 제한, 간단한 서버 측 이동/총격 검증만 구현한 **프로토타입**입니다. 정교한 총기 모델, 벽 충돌, 탄창/재장전, 모바일 자동 가로 전환, 신고/차단, 악용 방지 강화 등은 추후 개선이 필요합니다.
- 모바일은 브라우저에서 화면을 직접 가로로 회전하세요.
- 공개 채팅은 불특정 다수가 사용할 수 있으므로 실제 공개 운영 전 신고/차단/금칙어/운영자 관리 기능이 필요합니다.
