STUPID ANIMALS v0.5
v0.4 전체 기능 포함.
수정: 모바일 조이스틱 전후 이동 반전 버그 보정.
PC: P키 또는 '마우스 잠금' 버튼으로 브라우저 Pointer Lock을 요청합니다. 잠금 시 마우스 포인터가 숨겨지고 마우스 이동으로 자유롭게 시점이 회전합니다. P키나 ESC로 해제하면 포인터가 다시 나타납니다. 마우스 오른쪽 버튼 드래그도 시점 회전 가능.
모바일: 오른쪽 시점 조작 버튼으로 터치 회전 활성/비활성 전환.
GitHub 최상위 파일 index.html, game.js 교체 후 Render 배포.
주의: 실제 모바일 기기 플레이 테스트는 수행되지 않았습니다.
